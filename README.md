# Shashi Suman Portfolio

A dark, premium, animated developer portfolio built from scratch with **Next.js**, **Tailwind CSS v4**, and **Motion** (Framer Motion successor).

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production build

```bash
npm run build
npm start
```

## Included

- Resume content incorporated into About, Experience, Projects, Skills, Education, Bootcamp, Certifications and Co-curricular-ready profile sections.
- Uploaded profile photo at `public/profile.png`.
- Futuristic tech background at `public/tech-bg.png`.
- Responsive navigation and mobile menu.
- Scroll progress indicator.
- Scroll-triggered reveals and hover interactions using Motion.
- Responsive dark glassmorphism visual system.
- Direct email/phone contact actions.
